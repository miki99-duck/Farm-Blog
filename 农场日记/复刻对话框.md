# 用 CSS 复刻星露谷的对话框

星露谷的 UI 有一种特别的「厚重感」：四层描边、内阴影、还有右下角那一道硬阴影。

这次我试着用纯 CSS 的 `box-shadow` 把它还原出来，意外地只需要几行代码。

关键在于——不要用 `border-radius` 做圆角，像素风要的是直角。

```css
.sv-panel{
  background:#f8e8c0;
  border:4px solid #c99c5e;
  box-shadow:
    0 0 0 4px #4a2c17,
    inset 0 0 0 3px #fff6dd,
    6px 8px 0 rgba(0,0,0,.28);
}
```

### 第1章 总览与面试地图（1500字）

### 第2章 IoC 容器与 Bean 生命周期（5000字，核心中的核心）
- 2.1 容器是什么：BeanFactory vs ApplicationContext 的区别与继承关系
- 2.2 BeanDefinition 是什么、从哪来：XML 解析 / 注解扫描 / @Configuration 配置类
- 2.3 Bean 创建流程：getBean 主流程时序（缓存检查 → 创建 → 属性填充 → 初始化）
- 2.4 Bean 生命周期：从实例化到销毁的完整钩子链，
  InitializingBean / @PostConstruct / init-method 的调用顺序 ★高频
- 2.5 三级缓存与循环依赖：为什么是三级不是两级；AOP 情况下为什么必须三级 ★★超高频
- 2.6 作用域与懒加载：singleton/prototype、@Lazy
- 图2：BeanDefinition 解析流程图；图3：getBean 创建时序图；
  图4：Bean 生命周期状态机图；图5：三级缓存循环依赖流程图
- 代码示例8段：自定义 BeanFactoryPostProcessor、
  三个初始化钩子同台演示输出顺序、@Scope("prototype")、
  循环依赖最小复现（A↔B）+ 单例池快照、
  ObjectFactory 三级缓存关键源码摘录（3行核心 if）、
  @Lazy 注入打破循环依赖
- 面试追问链：循环依赖默认支持哪种注入方式？构造器循环依赖为什么不行？
  多例能不能循环依赖？代理对象怎么进入三级缓存？（earlySingletonReference）

### 第3章 DI 依赖注入（2000字）
- 内容：@Autowired 的处理者（AutowiredAnnotationBeanPostProcessor）；
  构造器/setter/字段三种注入对比；@Qualifier/@Primary/@Resource 解析顺序
- 图6：@Autowired 解析流程图
- 代码3段：字段注入 vs 构造器注入对比（结合"为什么推荐构造器"）；
  @Primary + @Qualifier 搭配；@Resource 按名称注入
- 追问链：构造器注入为什么能天然防循环依赖？@Autowired 找不到多个候选怎么办？

### 第4章 AOP 实现原理（4000字）
- 4.1 动态代理：JDK Proxy vs CGLIB 的对比与选型（目标类有无接口）
- 4.2 Spring AOP 概念模型：Pointcut/Advice/Advisor 三者的关系
- 4.3 代理创建流程：AbstractAutoProxyCreator → wrapIfNecessary → 切面匹配 → 生成代理
- 4.4 常见失效场景：自调用（this.xxx()）不走代理 ★超高频；
  final 方法；代理对象内部同类调用
- 图7：JDK vs CGLIB 对比图；图8：代理创建时序图
- 代码5段：手写 JDK 动态代理 10 行对比 Spring AOP；
  @Aspect 通知类型（@Before/@AfterReturning/@Around 执行顺序）；
  自调用失效复现 + 解决（注入自身/AopContext.currentProxy）★；
  ProxyFactory 手动创建代理
- 追问链：JDK 代理为什么必须接口？CGLIB 对 final 类/方法的影响？
  @Transactional 依赖 AOP 吗？同类调用 @Transactional 为什么失效？

### 第5章 事务管理（3000字）
- 5.1 声明式事务原理：@Transactional → TransactionInterceptor → PlatformTransactionManager
- 5.2 传播行为速查：REQUIRED/REQUIRES_NEW/NESTED 等 7 种，决策树记忆
- 5.3 失效场景大全（重点）：自调用、异常被 try-catch 吞掉、
  Error 不回滚、非 public 方法、类未被 Spring 管理、数据库引擎不支持（MyISAM）★超高频
- 图9：传播行为决策树
- 代码4段：事务拦截器关键调用链摘录；
  自调用失效复现与解决；REQUIRES_NEW 两个事务互不影响演示；
  结合本项目：IotPersistenceService 批量入库 + 多数据源时的
  事务边界设计（@Transactional 只对主数据源生效，多数据源需 JTA 或业务补偿）
- 追问链：REQUIRED 内层抛异常外层能不能捕获继续？propagation 与 isolation 区别？
  多数据源事务怎么处理？

### 第7章 Spring Boot 自动装配（2500字）

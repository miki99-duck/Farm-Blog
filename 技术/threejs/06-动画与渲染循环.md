# 第6章 动画与渲染循环:让场景动起来

> 一句话讲清:**动画的本质是"每帧修改物体属性再重画";但帧率不是稳定的,要用
> THREE.Clock 按"真实时间差"驱动动画,才能做到任何机器上速度一致。**
> 本章目标:掌握 requestAnimationFrame 循环、Clock 时间驱动、自转/公转/弹跳/补间四种基础动画。

## 6.1 渲染循环回顾:帧是动画的最小单位

```js
// 基础循环(第1章见过):
function animate() {
  requestAnimationFrame(animate);   // 注册下一帧
  cube.rotation.y += 0.01;          // 每帧改一点
  renderer.render(scene, camera);   // 重画
}
animate();
```

**这个写法有个致命问题(面试考点):`cube.rotation.y += 0.01` 是"每帧加固定值"。
如果屏幕是 60Hz,每秒转 0.6 弧度;如果是 144Hz 电竞屏,每秒转 1.44 弧度——**速度不一样!**
而且帧率波动时动画会忽快忽慢。这就是引入 Clock 的原因。**

## 6.2 THREE.Clock:按"真实时间"驱动动画(★ 标准做法)

```js
const clock = new THREE.Clock();    // 创建一个时钟

function animate() {
  requestAnimationFrame(animate);
  const delta = clock.getDelta();   // ★ 距上一帧过去了多少秒(真实时间差)
  cube.rotation.y += delta;         // 每秒转 1 弧度 —— 与帧率无关,永远匀速!
  renderer.render(scene, camera);
}
animate();
```

**Clock.getDelta() 是什么?** 返回"距上一次调用 getDelta 过去了多少秒"(约 1/60)。
用它做增量,速度就变成"每秒多少单位"而不是"每帧多少单位"——**任何帧率下速度一致。**

### Clock 两种用法对比

```js
// 方式1:getDelta() —— 增量式,适合"每帧速度恒定"的动画
const delta = clock.getDelta();
mesh.position.x += 2 * delta;       // 每秒向右移动 2 个单位

// 方式2:getElapsedTime() —— 累计式,适合"基于时间的函数动画"(正弦/圆周)
const t = clock.getElapsedTime();   // 从启动到现在过了多少秒(累计)
mesh.position.y = Math.sin(t) * 2;  // 上下弹跳:随时间正弦变化,永远连续
```

**记忆:增量(delta)管"速度",累计(elapsed)管"波形"。**

## 6.3 四种基础动画:自转、公转、弹跳、缩放

```html
<script type="importmap">
  { "imports": {
      "three": "https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js",
      "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.160.0/examples/jsm/"
  } }
</script>
<script type="module">
  import * as THREE from 'three';
  import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

  const scene = new THREE.Scene();
  const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 100);
  camera.position.set(6, 4, 8);
  camera.lookAt(0, 0, 0);
  const renderer = new THREE.WebGLRenderer();
  renderer.setSize(window.innerWidth, window.innerHeight);
  document.body.appendChild(renderer.domElement);
  new OrbitControls(camera, renderer.domElement);

  scene.add(new THREE.AmbientLight(0xffffff, 0.5));
  const sun = new THREE.DirectionalLight(0xffffff, 1.5);
  sun.position.set(5, 10, 5);
  scene.add(sun);
  scene.add(new THREE.GridHelper(10, 10));

  // 中心小球(公转对象)
  const center = new THREE.Mesh(
    new THREE.SphereGeometry(0.4, 24, 16),
    new THREE.MeshStandardMaterial({ color: 0x3498db })
  );
  scene.add(center);

  // 外围小球(自转 + 公转)
  const orbit = new THREE.Mesh(
    new THREE.SphereGeometry(0.25, 24, 16),
    new THREE.MeshStandardMaterial({ color: 0xe74c3c })
  );
  scene.add(orbit);

  // 方块(弹跳 + 旋转)
  const box = new THREE.Mesh(
    new THREE.BoxGeometry(0.8, 0.8, 0.8),
    new THREE.MeshStandardMaterial({ color: 0x2ecc71 })
  );
  box.position.x = -3;
  scene.add(box);

  const clock = new THREE.Clock();

  function animate() {
    requestAnimationFrame(animate);
    const delta = clock.getDelta();       // 增量:速度恒定
    const t = clock.getElapsedTime();     // 累计:波形函数

    // 1. 自转:中心球绕自身 y 轴转
    center.rotation.y += delta * 2;       // 每秒 2 弧度

    // 2. 公转:外围球绕中心转(位置用三角函数算)
    orbit.position.x = Math.cos(t) * 2;   // 半径 2 的圆
    orbit.position.z = Math.sin(t) * 2;

    // 3. 弹跳:正弦波 + 取绝对值,产生"落地反弹"效果
    box.position.y = Math.abs(Math.sin(t * 2)) * 2;

    // 4. 呼吸缩放:0.8 ~ 1.2 之间来回
    const s = 1 + Math.sin(t * 3) * 0.2;
    box.scale.set(s, s, s);

    renderer.render(scene, camera);
  }
  animate();
</script>
```

**四种动画一句话总结:**

| 动画 | 公式 | 用途 |
|------|------|------|
| 自转 | `rotation.y += delta * speed` | 设备旋转、风扇 |
| 公转 | `position = (cos(t)*r, sin(t)*r)` | 卫星、环绕粒子 |
| 弹跳 | `position.y = abs(sin(t*speed)) * h` | 心跳、告警闪烁 |
| 呼吸 | `scale = 1 + sin(t) * amp` | 重点设备强调 |

## 6.4 告警闪烁(大屏必备)

```js
// 大屏最常见的动画:设备告警时"红色闪烁 + 呼吸"
const alertMat = new THREE.MeshStandardMaterial({
  color: 0xff0000,
  emissive: 0xff0000,
  emissiveIntensity: 1,
});

function animate() {
  requestAnimationFrame(animate);
  const t = clock.getElapsedTime();
  // 闪烁:emissiveIntensity 在 0.3 ~ 2.0 之间正弦变化
  alertMat.emissiveIntensity = 1.5 + Math.sin(t * 6) * 1.2;
  renderer.render(scene, camera);
}
```

## 6.5 补间动画:TWEEN(过渡动画,做"镜头切换"必备)

**TWEEN 是补间库:定义"从 A 到 B 花多长时间",它自动插值每帧的中间值。**

```html
<!-- 引入 TWEEN(注意:它独立于 three,单独 CDN) -->
<script src="https://cdn.jsdelivr.net/npm/@tweenjs/tween.js@21.3.0/dist/tween.umd.js"></script>
```

```js
// 相机缓动到目标位置(大屏"切视角"特效)
function flyTo(position, lookAt, duration = 1000) {
  const target = new THREE.Vector3(...position);
  const targetLook = new THREE.Vector3(...lookAt);

  new TWEEN.Tween(camera.position)
    .to({ x: target.x, y: target.y, z: target.z }, duration)  // 相机位置插值
    .easing(TWEEN.Easing.Quadratic.InOut)                     // 缓动函数:先快后慢
    .start();
}

// 渲染循环里每帧调用 TWEEN.update() 让它推进
function animate() {
  requestAnimationFrame(animate);
  TWEEN.update();       // ★ 每帧必须调用,补间才会推进
  renderer.render(scene, camera);
}
```

**TWEEN 三要素:起点(当前值)、终点(.to)、时间(.to 的第二个参数)。**
每帧 `TWEEN.update()` 会根据已过时间算出当前值,赋给目标对象。

**面试考点:补间 vs 手写动画?** 手写适合简单匀速/波形动画;补间适合"从一个状态过渡到另一个状态"
(相机切换、位置移动),还自带缓动函数(先快后慢/回弹),代码可读性高。

## 6.6 常见坑汇总

| # | 坑 | 现象 | 解决 |
|---|----|------|------|
| 1 | 每帧加固定值 | 高刷屏动画飞快 | 用 `clock.getDelta()` 乘以速度 |
| 2 | getDelta 在多处调用 | 某处速度异常 | getDelta 每次调用会重置计时,一个循环只调用一次 |
| 3 | 忘了 requestAnimationFrame | 只画一帧就停 | 循环函数里先注册下一帧 |
| 4 | TWEEN 不生效 | 物体没动 | 每帧调用 `TWEEN.update()` |
| 5 | 正弦动画突变 | 位置突然跳变 | 用 `getElapsedTime()`(累计)而不用 delta 累加 |
| 6 | 页面切后台回来 | 动画"跳一大步" | delta 过大时钳制:`Math.min(delta, 0.1)` |
| 7 | 动画卡顿 | 帧率低 | 见第10章性能优化(几何体合并/减少光源/LOD) |

## 6.7 面试自测(追问链)

**Q1:为什么不能用"每帧加固定值"做动画?**
一句话:"帧率不固定,60Hz 和 144Hz 屏幕速度不同;应该用真实时间差(delta)驱动,保证任何设备速度一致。"
追问:怎么拿时间差?(THREE.Clock 的 getDelta,返回距上一帧的秒数)

**Q2:getDelta 和 getElapsedTime 区别?**
一句话:"delta 是距上一帧的增量,适合速度恒定动画;elapsed 是累计运行时间,适合正弦/圆周等波形动画。"
追问:为什么弹跳用 elapsed?(位置是时间的函数,用累计时间算 sin 才连续,用 delta 累加会漂移)

**Q3:requestAnimationFrame 和 setInterval 区别?**
一句话:"raf 由浏览器在重绘前调用,帧率匹配屏幕、切后台自动暂停;setInterval 固定间隔,容易丢帧和耗电。"
追问:动画卡了怎么办?(先查渲染开销,见第10章;raf 本身不会导致卡)

**Q4:TWEEN 补间是什么?**
一句话:"补间库:定义起点→终点→时长,自动插值中间值,适合相机/位置过渡动画。"
追问:为什么不用手写?(手写要自己算插值和缓动;TWEEN 内置缓动函数、代码清晰)

**Q5:大屏告警闪烁怎么实现?**
一句话:"emissiveIntensity 随时间正弦变化,配合红色 emissive,实现呼吸闪烁。"
追问:为什么用 emissive 不用光源?(自发光不影响性能、不照亮周围,适合 UI 强调)

# 第4章 光源与阴影:让场景"活"起来

> 一句话讲清:**没有光,受光材质(MeshStandardMaterial 等)就是全黑——光的类型决定光影效果,
> 阴影不是自动的,要"光源开 + 物体开 + 接收面开"三开关全开才显示。**
> 本章目标:会用 4 种光源,能调出正确的阴影,避开"场景太暗/太亮/没阴影"三大坑。

## 4.1 四种光源:一表看懂

| 光源 | 效果 | 参数 | 典型用途 |
|------|------|------|---------|
| `AmbientLight` | 环境光:均匀照亮所有面,无方向无阴影 | color / intensity | 保底亮度,防止全黑 |
| `DirectionalLight` | 平行光:像太阳,方向一致,有阴影 | color / intensity / position | 主光源(默认太阳) |
| `PointLight` | 点光源:像灯泡,从一点向四周发光 | color / intensity / distance | 路灯、灯泡、局部补光 |
| `SpotLight` | 聚光灯:像手电筒,锥形光束 | color / intensity / angle | 舞台、射灯、聚焦展示 |

```js
// 最常用的组合:环境光保底 + 平行光做主光
scene.add(new THREE.AmbientLight(0xffffff, 0.5));          // 均匀照亮,防全黑
const sun = new THREE.DirectionalLight(0xffffff, 1);       // 主光源
sun.position.set(10, 20, 10);                               // 光源位置(方向:从这指向原点)
scene.add(sun);

// 点光源:局部补光(比如设备柜旁边的小灯)
const lamp = new THREE.PointLight(0xffaa00, 1, 10);        // 颜色 / 强度 / 最大照射距离
lamp.position.set(3, 2, 0);
scene.add(lamp);
```

**关键理解(面试常问):AmbientLight 有方向吗?** 没有——它均匀加到每个面的颜色上,
不产生阴影、没有明暗变化,只负责"保底可见"。**真正产生立体感的是平行光/点光/聚光。**

**light.intensity 的坑**:不同版本的 Three.js 强度单位不同(旧版 DirectionalLight 默认 1 就很亮,
新版 PBR 光照强度受物理单位影响)。**经验值**:Ambient 0.3~0.6,主平行光 1~2,
场景还是暗就加到 2~3,而不是疯狂加光源数量(光源越多越卡)。

## 4.2 阴影:三开关全开才显示(★ 高频坑)

阴影不是"自动的"。要让阴影出现,需要同时满足:

```js
// 开关1:渲染器开启阴影
renderer.shadowMap.enabled = true;
// 可选:调阴影质量(默认 PCFSoftShadowMap 够用)
renderer.shadowMap.type = THREE.PCFSoftShadowMap;

// 开关2:光源开启阴影 + 设置阴影参数
const sun = new THREE.DirectionalLight(0xffffff, 1);
sun.position.set(10, 20, 10);
sun.castShadow = true;               // 光源决定"谁会产生影子"
sun.shadow.mapSize.set(1024, 1024);  // 阴影贴图分辨率(越大越清晰,越耗性能)
sun.shadow.camera.left = -10;        // 阴影相机范围(阴影"贴图"是光源视角渲染的)
sun.shadow.camera.right = 10;
sun.shadow.camera.top = 10;
sun.shadow.camera.bottom = -10;
scene.add(sun);

// 开关3:物体设置 castShadow + 地面设置 receiveShadow
const box = new THREE.Mesh(new THREE.BoxGeometry(1, 1, 1), new THREE.MeshStandardMaterial({ color: 0x3498db }));
box.castShadow = true;               // 这个物体"投出"阴影
box.position.y = 0.5;
scene.add(box);

const floor = new THREE.Mesh(
  new THREE.PlaneGeometry(10, 10),
  new THREE.MeshStandardMaterial({ color: 0xcccccc, side: THREE.DoubleSide })
);
floor.rotation.x = -Math.PI / 2;
floor.receiveShadow = true;          // 这个物体"接收"阴影
scene.add(floor);
```

**记口诀:渲染器开关 + 光源 castShadow + 物体 castShadow + 地面 receiveShadow——4 个条件,缺一不可。**

### 阴影常见坑

| # | 现象 | 原因 | 解决 |
|---|------|------|------|
| 1 | 开了还是没阴影 | 漏了某个开关(最常见:忘 renderer.shadowMap.enabled) | 四开关检查一遍 |
| 2 | 阴影有"条纹" | mapSize 太小 | `sun.shadow.mapSize.set(2048, 2048)` |
| 3 | 阴影被"切掉" | 阴影相机范围太小(物体超出 left/right 范围) | 调大 shadow.camera 的 left/right/top/bottom |
| 4 | 阴影闪烁/抖动 | 阴影相机 near/far 范围不当 | 调整 sun.shadow.camera.near/far |
| 5 | 点光源阴影太糊 | PointLight 阴影是六面立方体贴图,开销大 | 优先用平行光;或缩小 distance |

## 4.3 三种材质对光的反应:为什么物体是黑的

```js
// 记住:Basic 材质不受光(永远亮),Standard/Lambert/Phong 受光(没光就黑)
const a = new THREE.MeshBasicMaterial({ color: 0xff0000 });      // 无光也亮
const b = new THREE.MeshLambertMaterial({ color: 0xff0000 });    // 无光 = 黑!
const c = new THREE.MeshStandardMaterial({ color: 0xff0000 });   // 无光 = 黑!

// 场景只有 AmbientLight 时,Standard 材质看起来"发灰"
// 原因:环境光均匀加,没有明暗对比 → 物体"平"了
// 加 DirectionalLight 后,受光面亮、背光面暗 → 立体感出现
```

**"物体是黑的"三大原因排查(面试高频追问):**

1. 材质不受光 → 用的是 Standard/Lambert/Phong,但场景一个光源都没有。
2. 光源 intensity 太低 → 加 AmbientLight 0.3~0.6 + DirectionalLight 1~2。
3. 光源位置不对 → 光源在物体"背面"或离得太远,物体完全背光。

## 4.4 常用辅助:光源可视化(调试神器)

```js
// 灯光辅助:把光源位置/方向画出来,调试时一眼看到光在哪
scene.add(new THREE.DirectionalLightHelper(sun));   // 平行光:画一条方向线
scene.add(new THREE.PointLightHelper(lamp));        // 点光源:画一个点 + 照射范围球

// 阴影相机辅助:看阴影贴图的"拍摄范围"(调 shadow.camera 范围时很有用)
scene.add(new THREE.CameraHelper(sun.shadow.camera));
```

## 4.5 大屏灯光推荐配置(直接用)

```js
// IoT 大屏"干净明亮"配方:
scene.add(new THREE.AmbientLight(0xffffff, 0.6));           // 保底
const mainLight = new THREE.DirectionalLight(0xffffff, 1.5);
mainLight.position.set(5, 10, 5);                           // 从右上打下来
mainLight.castShadow = true;
scene.add(mainLight);

const fillLight = new THREE.DirectionalLight(0xffffff, 0.4); // 补光:从反方向打,减少死黑
fillLight.position.set(-5, 3, -5);
scene.add(fillLight);
```

**为什么大屏要"环境光 + 主光 + 补光"三件套?** 环境光保证全场景可见,主光制造立体感,
补光消除背光面的死黑——这是 3D 场景最基础的三点布光法,面试能讲出这一句就够亮眼。

## 4.6 常见坑汇总

| # | 坑 | 现象 | 解决 |
|---|----|------|------|
| 1 | 受光材质没光源 | 全黑 | AmbientLight + DirectionalLight 组合 |
| 2 | 忘 renderer.shadowMap.enabled | 三开关开了也没阴影 | 渲染器开关是总闸 |
| 3 | 忘 castShadow/receiveShadow | 有光没影 | 物体 cast,地面 receive |
| 4 | 阴影相机范围小 | 阴影被切 | 调 shadow.camera left/right/top/bottom |
| 5 | mapSize 太小 | 阴影锯齿/条纹 | 1024→2048 |
| 6 | 光源数量太多 | 卡顿 | 优先 2~3 个高质量光,别堆 10 个 |
| 7 | AmbientLight 强度太高 | 画面发灰发白,无立体感 | Ambient 0.3~0.6,别超过 0.8 |

## 4.7 面试自测(追问链)

**Q1:4 种光源分别是什么?**
一句话:"环境光均匀照亮、平行光像太阳、点光源像灯泡、聚光灯像手电筒。"
追问:环境光有方向/阴影吗?(没有——均匀加色,不产生明暗和阴影)

**Q2:为什么 MeshStandardMaterial 没加光源是全黑的?**
一句话:"Standard 材质要做光照计算,输入光强为 0 输出就是黑;Basic 材质不做光照计算,所以永远亮。"
追问:怎么排查"物体黑"?(先查有没有光 → 查强度 → 查光源位置)

**Q3:阴影要满足哪些条件?**
一句话:"渲染器 shadowMap.enabled + 光源 castShadow + 物体 castShadow + 接收面 receiveShadow,四个开关。"
追问:阴影是实时计算的吗?(是——光源视角渲染一张深度贴图,再投影到接收面上,所以 mapSize 影响清晰度和性能)

**Q4:什么是三点布光?**
一句话:"环境光保底 + 主光制造立体感 + 补光消除死黑,是 3D 场景最基础的光照配置。"
追问:为什么不用 10 个光源?(每个光源都要参与逐像素光照计算,光源越多越卡)

**Q5:阴影贴图 mapSize 大了会怎样?**
一句话:"更清晰,但更耗性能——因为要多渲染一张高分辨率深度图。"
追问:大屏怎么平衡?(移动端/大屏用 1024,特写镜头用 2048;能不开阴影的场景就不开)

# 第7章 交互与射线检测:点击、悬浮、拾取

> 一句话讲清:**3D 里没有"点击了哪个物体"这种现成事件,要用 Raycaster(射线检测):
> 从相机位置向鼠标方向射一条"看不见的射线",看它先撞到哪个物体——这就是拾取原理。**
> 本章目标:掌握 Raycaster 点击拾取、hover 高亮、点击弹出信息,这是 IoT 大屏"点设备看数据"的核心。

## 7.1 原理:射线检测(Raycasting)

**为什么 3D 不能直接用 DOM 的 click 事件?** 因为物体不是 HTML 元素,而是画布上的一堆像素。
浏览器只知道"你点了屏幕的 (x, y)",不知道这个像素属于哪个 3D 物体。所以要自己算:

```
鼠标点屏幕 (x, y)
   │
   ▼
转成 NDC 坐标(-1 ~ 1)  ← 屏幕坐标系的归一化
   │
   ▼
从相机发出"射线"穿过这个点  ← Raycaster
   │
   ▼
射线与场景中的物体求交    ← intersectObjects()
   │
   ▼
最近的交点 = 被点击的物体
```

```js
// Raycaster 三行核心:
const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();

// 1. 鼠标移动/点击时,记录屏幕位置并转成 NDC 坐标
pointer.x = (event.clientX / window.innerWidth) * 2 - 1;   // x: 0~width → -1~1
pointer.y = -(event.clientY / window.innerHeight) * 2 + 1; // y: 反转(屏幕 y 向下,NDC y 向上)

// 2. 从相机位置朝鼠标方向发射射线
raycaster.setFromCamera(pointer, camera);

// 3. 检测射线与哪些物体相交(返回按距离排序的交点数组)
const hits = raycaster.intersectObjects(scene.children);
if (hits.length > 0) {
  console.log('点中了:', hits[0].object);   // 最近的交点
}
```

## 7.2 完整示例:点击立方体改变颜色(★ 必跑通)

```html
<script type="importmap">
  { "imports": {
      "three": "https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js",
      "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.160.0/examples/jsm/"
  } }
</script>
<script type="module">
  import * as THREE from 'three';
  import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

  const scene = new THREE.Scene();
  const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 100);
  camera.position.set(4, 3, 6);
  camera.lookAt(0, 0, 0);
  const renderer = new THREE.WebGLRenderer();
  renderer.setSize(window.innerWidth, window.innerHeight);
  document.body.appendChild(renderer.domElement);
  new OrbitControls(camera, renderer.domElement);

  scene.add(new THREE.AmbientLight(0xffffff, 0.5));
  const sun = new THREE.DirectionalLight(0xffffff, 1.5);
  sun.position.set(5, 10, 5);
  scene.add(sun);

  // 三个可点击的立方体(给每个存个自定义数据)
  const colors = [0x3498db, 0xe74c3c, 0x2ecc71];
  const clickables = [];
  for (let i = 0; i < 3; i++) {
    const mesh = new THREE.Mesh(
      new THREE.BoxGeometry(1, 1, 1),
      new THREE.MeshStandardMaterial({ color: colors[i] })
    );
    mesh.position.x = (i - 1) * 2;
    mesh.userData.id = i;                 // ★ 自定义数据:拾取后能拿到业务信息
    mesh.userData.name = '设备' + (i + 1);
    scene.add(mesh);
    clickables.push(mesh);
  }

  // Raycaster 相关
  const raycaster = new THREE.Raycaster();
  const pointer = new THREE.Vector2();

  // 点击事件:只检测 clickables,别测全部场景(性能优化)
  renderer.domElement.addEventListener('click', (event) => {
    pointer.x = (event.clientX / window.innerWidth) * 2 - 1;
    pointer.y = -(event.clientY / window.innerHeight) * 2 + 1;

    raycaster.setFromCamera(pointer, camera);
    const hits = raycaster.intersectObjects(clickables);   // ★ 只测目标数组

    if (hits.length > 0) {
      const obj = hits[0].object;
      obj.material.color.set(0xffaa00);                     // 点中的变橙色
      console.log('点击了', obj.userData.name, 'id=', obj.userData.id);
      // 实际项目:这里弹信息框 / 调后端接口查设备详情
    } else {
      console.log('没点中任何设备');
    }
  });

  function animate() {
    requestAnimationFrame(animate);
    renderer.render(scene, camera);
  }
  animate();
</script>
```

**两个关键点(面试必答):**

1. **`intersectObjects(clickables)` 只检测你传入的数组**,不是 scene 里所有物体。
   大屏场景有成百上千物体,全测会很慢——**只测"可交互"的那批**。
2. **`userData` 是给物体挂业务数据的标准位置**(id/名称/状态/地址),
   拾取后 `hits[0].object.userData` 直接拿,不用额外 map 查找。

## 7.3 hover 高亮:鼠标悬浮变亮/变大

```js
// 鼠标移动时检测(注意:高频触发,性能敏感)
renderer.domElement.addEventListener('mousemove', (event) => {
  pointer.x = (event.clientX / window.innerWidth) * 2 - 1;
  pointer.y = -(event.clientY / window.innerHeight) * 2 + 1;

  raycaster.setFromCamera(pointer, camera);
  const hits = raycaster.intersectObjects(clickables);

  // 先恢复上一个高亮的
  if (hovered) {
    hovered.material.emissive.set(0x000000);   // 去掉自发光
    hovered.scale.set(1, 1, 1);                // 恢复大小
    hovered = null;
  }

  if (hits.length > 0) {
    hovered = hits[0].object;
    hovered.material.emissive.set(0x222222);   // 加一点自发光 = 变亮
    hovered.scale.set(1.1, 1.1, 1.1);          // 轻微放大
    renderer.domElement.style.cursor = 'pointer';  // 鼠标变手型
  } else {
    renderer.domElement.style.cursor = 'default';
  }
});
```

**hover 的坑:** mousemove 每帧触发很多次,如果场景大、检测数组大,会卡。
优化方向(第10章细讲):只检测可交互数组、必要时用 throttle、或降低检测频率。

## 7.4 设备信息面板:点击弹窗(大屏实战)

```js
// 点击设备后显示信息 —— 不用 alert,用 HTML 覆盖层
// 屏幕右下角放一个隐藏的 div
// <div id="info" style="display:none; position:fixed; right:20px; bottom:20px;
//       background:rgba(0,0,0,0.8); color:#fff; padding:16px; border-radius:8px; z-index:10"></div>

const infoEl = document.getElementById('info');

renderer.domElement.addEventListener('click', (event) => {
  pointer.x = (event.clientX / window.innerWidth) * 2 - 1;
  pointer.y = -(event.clientY / window.innerHeight) * 2 + 1;
  raycaster.setFromCamera(pointer, camera);
  const hits = raycaster.intersectObjects(clickables);

  if (hits.length > 0) {
    const d = hits[0].object.userData;
    infoEl.style.display = 'block';
    infoEl.innerHTML = `
      <h3>${d.name}</h3>
      <p>设备ID: ${d.id}</p>
      <p>状态: ${d.status}</p>
      <p>温度: ${d.temperature}°C</p>
      <p>压力: ${d.pressure} MPa</p>
    `;
    // 业务上:这里通常是 fetch(`/api/device/${d.id}`) 拉实时数据
  } else {
    infoEl.style.display = 'none';
  }
});
```

**大屏交互套路:Raycaster 拾取到设备 → userData 拿 id → 请求后端接口 → 渲染信息面板。**
这就是"3D 大屏点设备看数据"的完整链路,面试讲这个非常加分。

## 7.5 进阶:拖拽物体(TransformControls)

```js
import { TransformControls } from 'three/addons/controls/TransformControls.js';

// 给选中的物体加"拖拽手柄"(移动/旋转/缩放)
const transformControls = new TransformControls(camera, renderer.domElement);
transformControls.setMode('translate');        // 模式:translate/rotate/scale
transformControls.attach(selectedMesh);        // 绑定要操作的物体
scene.add(transformControls);

// 监听拖拽事件(拖完保存位置,如"设备摆放编辑器")
transformControls.addEventListener('dragging-changed', (e) => {
  controls.enabled = !e.value;   // 拖拽时禁用 OrbitControls,防止两个控制器打架
});
```

**坑:TransformControls 和 OrbitControls 会抢鼠标事件**,拖拽时要把 OrbitControls 禁用(enabled=false)。

## 7.6 常见坑汇总

| # | 坑 | 现象 | 解决 |
|---|----|------|------|
| 1 | y 坐标没反转 | 点不准/点偏 | NDC y = -(clientY / height) * 2 + 1,屏幕 y 向下 |
| 2 | 检测全部场景 | 点击卡顿 | `intersectObjects(可交互数组)`,别传 scene.children 全部 |
| 3 | 忘 setFromCamera | 射线方向不对 | 每次检测前必须 `raycaster.setFromCamera(pointer, camera)` |
| 4 | 点到"透明面" | 点不到后面的物体 | 检测数组里排除地面/辅助线,或按距离取最近的可交互物体 |
| 5 | hover 与 click 同时写 | 高亮丢失/闪烁 | hover 恢复逻辑放 mousemove 开头,click 单独处理 |
| 6 | 相机动了拾取失灵 | 点不到原来位置 | Raycaster 每帧基于当前 camera 计算,天然适配;检查是否用错旧相机引用 |
| 7 | TransformControls 与 OrbitControls 打架 | 拖拽同时视角乱转 | dragging-changed 时 controls.enabled = !e.value |

## 7.7 面试自测(追问链)

**Q1:为什么 3D 不能用普通 click 事件?**
一句话:"物体是画布上的像素不是 DOM 元素,浏览器只知道点击的屏幕坐标,不知道属于哪个 3D 物体,需要自己用射线检测算。"
追问:射线检测原理?(从相机位置向鼠标方向射射线,与物体求交,最近的交点就是点击目标)

**Q2:Raycaster 检测的核心步骤?**
一句话:"屏幕坐标转 NDC → setFromCamera 发射射线 → intersectObjects 求交。"
追问:NDC 坐标是什么?(归一化设备坐标,-1~1;x=(clientX/width)*2-1, y 要反转)

**Q3:为什么只检测部分物体?**
一句话:"intersectObjects 传入的数组决定检测范围,只测可交互物体,避免大场景全量检测卡顿。"
追问:场景有几千个物体怎么办?(只把可交互的放进数组;或用八叉树等空间索引,见第10章)

**Q4:userData 是干嘛的?**
一句话:"给物体挂自定义业务数据的标准字段,拾取后直接拿 id/名称/状态,不用额外查找。"
追问:大屏点设备看数据的完整链路?(拾取 → userData.id → fetch 接口 → 渲染信息面板)

**Q5:hover 高亮怎么做?**
一句话:"mousemove 里射线检测,命中就加 emissive/放大/改光标,离开就恢复。"
追问:高频 mousemove 会卡吗?(会——只检测小数组、必要时节流、降低频率)

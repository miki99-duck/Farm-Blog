# 第2章 几何体与材质:形状 + 外表 = 物体

> 一句话讲清:**3D 里没有"画一个物体"这种操作,只有"几何体(形状)+ 材质(外表)= 网格 Mesh",
> 三个对象拼起来就是一个能放进场景的物体。**
> 本章目标:认识常用几何体、会用 6 种基础材质,理解 Mesh 的三层结构(变换/几何体/材质)。

## 2.1 铁三角:Geometry(形状)+ Material(外表)= Mesh(物体)

```js
// 一个 Mesh 由三部分构成:
// geometry: 顶点数据(形状)——"是什么形状"
// material: 渲染参数(外表)——"什么颜色/质感"
// mesh:     把两者组合,并带上位置/旋转/缩放(transform)——"放在哪、多大"
const geometry = new THREE.BoxGeometry(1, 1, 1);          // 形状:立方体
const material = new THREE.MeshBasicMaterial({ color: 0x00aaff }); // 外表:纯蓝
const mesh = new THREE.Mesh(geometry, material);          // 物体
mesh.position.set(0, 1, 0);                               // 放到 (0,1,0)
mesh.rotation.y = Math.PI / 4;                            // 绕 y 轴转 45 度
mesh.scale.set(2, 2, 2);                                  // 放大 2 倍
scene.add(mesh);                                          // 放进场景
```

三个可复用规则(面试可答):

1. **同一几何体可配不同材质**:一个 shape 配红色/蓝色两个 material,生成两个不同颜色的 Mesh——材质不独占几何体。
2. **同一材质可配多个 Mesh**:一个 material 配给多个物体,改一次颜色全部生效。
3. **变换是"附加"的**:mesh.position/rotation/scale 只影响这一个 Mesh,不影响 geometry 本身。

## 2.2 常用几何体:一表看懂参数(记住 3 个就够)

| 几何体 | 样子 | 关键参数 | 一句话用途 |
|--------|------|----------|-----------|
| `BoxGeometry(w, h, d)` | 立方体 | 宽/高/深 | 箱子、楼房、设备柜 |
| `SphereGeometry(r, wSeg, hSeg)` | 球体 | 半径/经线分段/纬线分段 | 地球、点位、球泡 |
| `CylinderGeometry(rTop, rBottom, h, radialSeg)` | 圆柱/锥 | 上半径/下半径/高/分段 | 管道、柱子、烟囱 |
| `ConeGeometry(r, h)` | 圆锥 | 半径/高 | 屋顶、锥体 |
| `PlaneGeometry(w, h)` | 平面 | 宽/高 | 地面、墙面、告警面板 |
| `TorusGeometry(r, tube, radialSeg, tubularSeg)` | 圆环 | 主半径/管半径/分段 | 甜甜圈、环形轨道 |
| `CircleGeometry(r)` | 圆片 | 半径 | 圆点、光圈 |

```js
// 常用组合示例:一个"管道场景"里常用到圆柱 + 球体
const pipe = new THREE.Mesh(
  new THREE.CylinderGeometry(0.5, 0.5, 3, 32),   // 上下半径 0.5,高 3
  new THREE.MeshStandardMaterial({ color: 0x888888 })
);
const ball = new THREE.Mesh(
  new THREE.SphereGeometry(0.6, 32, 16),          // 半径 0.6,分段越多越圆
  new THREE.MeshStandardMaterial({ color: 0xff0000 })
);
```

**分段数是什么?** 3D 里"圆"其实是多边形近似的:分段越多越圆滑,顶点越多越耗性能。
`SphereGeometry(1, 32, 16)` 的 32/16 就是经纬分段数。面试常问:**"为什么球体分段多了会卡?"**
——顶点数翻倍增长,GPU 要处理的三角形变多。

## 2.3 材质家族:6 种材质怎么选

| 材质 | 受光? | 特性 | 用在哪 |
|------|-------|------|--------|
| `MeshBasicMaterial` | ❌ 不受光 | 纯色,永远"亮" | 调试、线框、发光元素、UI 面板 |
| `MeshLambertMaterial` | ✅ | 漫反射,性能好,无高光 | 哑光物体(墙面、塑料) |
| `MeshPhongMaterial` | ✅ | 漫反射+高光 | 有光泽的物体(金属感、陶瓷) |
| `MeshStandardMaterial` | ✅ | PBR 物理材质,最常用 | 真实感物体(推荐默认用这个) |
| `MeshNormalMaterial` | ❌ | 用法线方向当颜色(彩虹色) | 调试几何体形状 |
| `MeshMatcapMaterial` | ❌ | 贴图模拟光照,性能极好 | 移动端/大批量物体 |

```js
// 三种材质对比演示(同一几何体,三个位置)
const geo = new THREE.BoxGeometry(1, 1, 1);

const basic = new THREE.MeshBasicMaterial({ color: 0xff0000 });  // 1. 不受光:永远红色
const lambert = new THREE.MeshLambertMaterial({ color: 0xff0000 }); // 2. 受光:暗面会变暗
const standard = new THREE.MeshStandardMaterial({ color: 0xff0000, roughness: 0.4, metalness: 0.3 });
                                                                    // 3. PBR:粗糙度/金属度可控

const m1 = new THREE.Mesh(geo, basic);   m1.position.x = -2;
const m2 = new THREE.Mesh(geo, lambert); m2.position.x = 0;
const m3 = new THREE.Mesh(geo, standard);m3.position.x = 2;
scene.add(m1, m2, m3);   // scene.add 支持一次传多个

// 注意:受光材质必须配光源才看得清,否则全黑!下一章讲光源
```

**选材质的经验法则**:做真实感场景 → 默认 `MeshStandardMaterial`;
调试形状 → `MeshBasicMaterial` 或 `MeshNormalMaterial`;
性能敏感(大屏/移动端) → `MeshBasicMaterial` / `MeshMatcapMaterial`。

## 2.4 材质常用属性:透明、线框、双面

```js
const material = new THREE.MeshStandardMaterial({
  color: 0x00aaff,          // 颜色:十六进制 0x 或 CSS 字符串 '#00aaff'
  transparent: true,        // ★ 必须显式开启,透明才生效(高频坑)
  opacity: 0.5,             // 不透明度 0~1
  wireframe: true,          // 线框模式:只看三角形边线(调试用)
  side: THREE.DoubleSide,   // 渲染哪面:FrontSide(默认)/BackSide/DoubleSide
  emissive: 0x001122,       // 自发光颜色(受光材质也能"自己发光")
  roughness: 0.5,           // 粗糙度 0~1(StandardMaterial)
  metalness: 0.0,           // 金属度 0~1(StandardMaterial)
});
```

三个高频坑提前预警:

1. **transparent 不设 true**:opacity 设了 0.5 也不透明——`transparent: true` 必须和 opacity 成对出现。
2. **面片默认单面**:PlaneGeometry 从背面看是"透明的"。做地面/墙要设 `side: THREE.DoubleSide`,
   或把平面反过来(rotation.x = -Math.PI / 2 配合正面朝上)。
3. **emissive 不是"发光体"**:它只是把颜色加到表面,不会照亮周围的物体(真正的光源是第4章)。

## 2.5 常用几何体 + 变换组合:一个"小场景"示例

```html
<script type="importmap">
  { "imports": {
      "three": "https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js",
      "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.160.0/examples/jsm/"
  } }
</script>
<script type="module">
  import * as THREE from 'three';

  // 场景三要素
  const scene = new THREE.Scene();
  const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
  camera.position.set(5, 4, 8);
  camera.lookAt(0, 0, 0);
  const renderer = new THREE.WebGLRenderer();
  renderer.setSize(window.innerWidth, window.innerHeight);
  document.body.appendChild(renderer.domElement);

  // 桌面(平面):注意要翻平 + 双面
  const floor = new THREE.Mesh(
    new THREE.PlaneGeometry(10, 10),
    new THREE.MeshStandardMaterial({ color: 0xcccccc, side: THREE.DoubleSide })
  );
  floor.rotation.x = -Math.PI / 2;   // 平面默认立在 xy 面,绕 x 转 -90 度躺平
  floor.position.y = -0.5;
  scene.add(floor);

  // 四个物体排一排:不同几何体
  const items = [
    [new THREE.BoxGeometry(1, 1, 1), 0x3498db, -3],
    [new THREE.SphereGeometry(0.6, 32, 16), 0xe74c3c, -1],
    [new THREE.CylinderGeometry(0.4, 0.4, 1.2, 32), 0x2ecc71, 1],
    [new THREE.TorusGeometry(0.5, 0.2, 16, 32), 0xf39c12, 3],
  ];
  items.forEach(([geometry, color, x]) => {
    const mesh = new THREE.Mesh(geometry, new THREE.MeshStandardMaterial({ color, roughness: 0.5 }));
    mesh.position.x = x;
    mesh.position.y = 0.5;
    scene.add(mesh);
  });

  // 受光材质需要光源:加一个方向光 + 环境光(第4章细讲,先照用)
  scene.add(new THREE.DirectionalLight(0xffffff, 1));
  scene.add(new THREE.AmbientLight(0xffffff, 0.4));

  function animate() {
    requestAnimationFrame(animate);
    renderer.render(scene, camera);
  }
  animate();
</script>
```

## 2.6 常见坑汇总

| # | 坑 | 现象 | 解决 |
|---|----|------|------|
| 1 | 受光材质没加光源 | 物体全黑 | 用 `MeshStandardMaterial` 必须加 `DirectionalLight` / `AmbientLight` |
| 2 | 忘了 `transparent: true` | opacity 不生效 | transparent 与 opacity 成对设置 |
| 3 | PlaneGeometry 单面 | 从一侧看"消失" | `side: THREE.DoubleSide` 或旋转到正面 |
| 4 | 平面方向不对 | 地面立着/看不见 | 平面默认在 xy 面,地面要 `rotation.x = -Math.PI/2` |
| 5 | 分段数太大 | 卡顿 | 移动端球体 16~24 段够用;大屏别超 64 |
| 6 | 颜色格式混用 | 颜色不生效/报错 | 统一 `0xRRGGBB`(数字)或 `'#RRGGBB'`(字符串),别混 |
| 7 | 几何体参数记错 | 形状出乎意料 | CylinderGeometry(rTop, rBottom, h):上下半径可不同 → 能做出锥形 |

## 2.7 面试自测(追问链)

**Q1:Mesh 由哪几部分组成?**
一句话:"几何体(形状)+ 材质(外表),Mesh 自身带位置/旋转/缩放变换。"
追问1:几何体和材质能不能复用?(能:一几何多材质、一材质多 Mesh)
追问2:修改 mesh.scale 影响 geometry 吗?(不影响,变换叠加在渲染时计算)

**Q2:6 种常用材质怎么选?**
一句话:"真实感用 Standard,哑光用 Lambert,光泽用 Phong,调试用 Basic/Normal,性能敏感用 Matcap。"
追问:BasicMaterial 为什么不受光?(它直接把颜色输出到像素,不做光照计算——所以永远亮)

**Q3:为什么球体分段越多越卡?**
一句话:"分段决定顶点数,顶点数决定 GPU 要处理的三角形数,翻倍增长耗性能。"
追问:怎么平衡?(半径不变时,距离远的球用低分段;或换 Matcap 材质)

**Q4:transparent 与 opacity 的关系?**
一句话:"opacity 是目标透明度,transparent:true 是开关——不打开开关,opacity 不生效。"
追问:透明物体渲染有什么坑?(渲染顺序问题:透明物体要按深度排序,后续章节展开)

**Q5:PlaneGeometry 默认是单面还是双面?**
一句话:"单面(正面是 +z 方向),从背面看会消失,需要 DoubleSide。"
追问:为什么默认单面?(性能优化——一半三角形直接跳过,GPU 更省)

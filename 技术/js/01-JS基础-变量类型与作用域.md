# 第1章 JS 基础：变量、类型与作用域

> 一句话讲清：**JS 的变量是"标签"不是"盒子"——值是主角；类型是运行期的、动态的；
> 作用域是词法的（写在哪决定能看到哪）。**
> Java 对照：let/const ≈ Java 的局部变量，var ≈ 旧时代的"公共静态"（容易踩坑）。

## 1.1 三个变量声明：var / let / const（面试必考区别）

```js
// var：函数级作用域，可重复声明，有"变量提升"——旧时代的坑
var a = 1;
var a = 2;          // ❌ 不报错！可重复声明

// let：块级作用域，不可重复声明，有"暂时性死区"
let b = 1;
// let b = 2;       // ❌ SyntaxError: 已声明

// const：常量，块级作用域（引用类型的"值"可变！见 1.3）
const c = 3;
// c = 4;           // ❌ 报错
```

现代规范：**一律 let/const，where? let for 可变、const for 不可变（默认 const，需要改才 let）。**

### var 的坑：变量提升（Hoisting）

```js
console.log(x);   // undefined —— 不报错！因为 var x 被"提升"到顶部，只是还没赋值
var x = 10;

// 等价于幕后：
// var x;
// console.log(x); // undefined
// x = 10;
```

let/const 修正了这一点：

```js
console.log(y);   // ❌ ReferenceError: Cannot access 'y' before initialization
let y = 10;       // 暂时性死区：声明之前访问直接报错，不给"undefined 错觉"
```

面试标准答案：**"var 函数作用域+可重复声明+提升（值为 undefined 不报错）；
let/const 块级作用域+不可重复声明+暂时性死区；const 还能防基本类型被重新赋值。"**

## 1.2 类型系统：8 种类型，7 种是"基本"

```js
// 基本类型（7 种）：存"值"本身，复制时是拷贝
typeof 42          // "number"
typeof 'abc'       // "string"
typeof true        // "boolean"
typeof undefined   // "undefined"
typeof null        // "object"（历史 bug，null 其实是基本类型）
typeof Symbol()    // "symbol"
typeof 10n         // "bigint"

// 引用类型（1 种）：存"引用"，复制时是共享
typeof {}          // "object"
typeof []          // "object"（数组是对象！）
typeof function(){}// "function"（函数是对象，typeof 特殊对待）
```

关键理解（面试最常考）：

```js
// 基本类型按值传递：修改副本不影响原值
let m = 1;
let n = m;
n = 2;
console.log(m);   // 1 —— m 没变

// 引用类型按引用共享：修改"同一个对象"
let obj = { count: 1 };
let obj2 = obj;          // 指向同一个对象
obj2.count = 99;
console.log(obj.count);  // 99 —— 改的是同一个对象！
```

Java 对照：基本类型 ≈ int/String 值传递；引用类型 ≈ 对象引用赋值（指向堆上同一个对象）。

## 1.3 const 与引用类型的"误会"

```js
const user = { name: '张三' };
user.name = '李四';       // ✅ 不报错！const 锁的是"引用"，不是"内容"
// user = { name: '王五' }; // ❌ 重新赋值（换引用）才报错

const arr = [1, 2, 3];
arr.push(4);              // ✅ 可以
arr[0] = 0;               // ✅ 可以
```

面试高频：**"const 声明的对象为什么还能改？"——因为 const 冻结的是变量名指向的引用，
对象内部内容本来就可变；真想冻结用 Object.freeze()（浅冻结）。**

## 1.4 动态类型与隐式转换（JS 的"魔法"和"坑"）

```js
// 类型是运行期的：同一个变量可以变类型
let x = 'hello';
x = 42;          // ✅ JS 不报错，Java 里这是编译错误

// 隐式转换：+ 号遇字符串就拼接，其余运算会转数字
console.log('5' + 3);        // "53"（拼接！）
console.log('5' - 3);        // 2（减号只认数字）
console.log('5' * '2');      // 10

console.log(1 + '2' + 3);    // "123"（从左到右，先拼成"12"再拼"3"）
console.log(1 + 2 + '3');    // "33"（先算 1+2=3，再拼接）

// 假值(falsy)清单：面试必背
// false、0、''（空串）、null、undefined、NaN —— 其余全是真值
if (0)        { /* 不执行 */ }
if ('')       { /* 不执行 */ }
if ('0')      { /* 执行！非空字符串是真值 */ }
```

实用原则（避免"魔法"误伤）：
- 拼接统一用模板字符串（见 1.6），别靠 + 隐式拼接。
- 数值转换显式写：Number('5')、parseInt('10px', 10)
- 判空写清楚：`x == null`（同时匹配 null 和 undefined，推荐）而不是 `!x`（连 0 和 '' 一起吃进去）

## 1.5 == vs ===（必考送分/送命题）

```js
'5' == 5    // true  —— == 会做类型转换
'5' === 5   // false —— === 类型和值都要相等（严格相等）

null == undefined   // true（历史设计）
null === undefined  // false
```

规范：**开发一律用 ===（或 == null 判断空），永远不用 == 做比较运算。**

面试升级问：`[] == false` 是多少？答：true（空数组先转字符串 ""，再转数字 0）。
这类题不考智商考记忆，会答不如会规避——**用 === 就没有这些题**。

## 1.6 字符串与模板字符串（写前端最高频）

```js
// 老式拼接：又丑又容易错
const name = '张三';
console.log('你好，' + name + '！你是第' + (1 + 1) + '位。');

// 模板字符串：反引号 + ${}，多行也不用 \n（RuoYi 代码里到处都是）
const msg = `你好，${name}！你是第${1 + 1}位。`;
const html = `
  <div class="card">
    <h3>${name}</h3>
  </div>
`;   // 多行原生支持

// 表达式中可以放任何 JS：三元、方法调用
const status = `当前状态：${device.online ? '在线' : '离线'}`;
```

## 1.7 作用域：词法作用域（写在哪，决定了能看到哪）

```js
let globalVar = '全局';

function outer() {
  let outerVar = '外层';
  function inner() {
    let innerVar = '内层';
    console.log(globalVar);  // ✅ 能看到全局
    console.log(outerVar);   // ✅ 能看到外层（闭包基础）
  }
  // console.log(innerVar);  // ❌ 看不到内层
}
// console.log(outerVar);     // ❌ 看不到函数内部
```

作用域链规则：**内层能访问外层，外层不能访问内层**——和 Java 的方法嵌套同理，
但 JS 的函数可以嵌套定义（Java 方法不能直接嵌套），所以"闭包"是 JS 特有概念（第2章讲）。

块级作用域实战（for 循环经典坑）：

```js
// var + for：所有回调看到的都是同一个 i（因为 var 是函数级）
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i));   // 输出 3 3 3（循环结束时 i 已经变 3）
}

// let + for：每次迭代一个独立的 i（块级）
for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log(j));   // 输出 0 1 2 ✅
}
```

面试必考："for 里 setInterval 为什么全是最后一个值？"答案就是 var 的函数级作用域；
**用 let 声明循环变量直接修复**（这也是 let 存在的主要理由之一）。

## 1.8 大坑与排查

| 坑 | 现象 | 原因/解法 |
|----|------|----------|
| 变量变成 undefined | 没初始化 / var 提升 | 用 let/const，检查声明 |
| 函数外也能改函数内变量 | var 漏声明 | 严格模式 'use strict' 会报错；统一 let |
| 隐式全局变量 | 赋值给未声明变量 | a = 1 不报错→全局污染；先声明 |
| 判断数组用 typeof | "object" 不区分 | Array.isArray(arr) |
| 深拷贝成浅拷贝 | 复制引用共享改动 | structuredClone() 或 JSON 序列化（注意 undefined/函数丢失） |
| NaN 不等于自己 | NaN === NaN 是 false | Number.isNaN(x) 判断 |

## 1.9 面试自测

- Q：var/let/const 区别？★
  A：作用域（函数/块）、重复声明、提升（暂时性死区）、const 防重新赋值。
- Q：基本类型和引用类型的区别？★
  A：值 vs 引用；赋值/传参时拷贝值 or 共享对象；const 拦不住对象内部变化。
- Q：== 和 ===？★
  A：=== 类型+值；== 会隐式转换（禁止）；== null 判断空除外。
- Q：为什么 for 里的 var 是坑？
  A：函数级作用域共享一个 i；let 每次迭代独立。
- Q：typeof null 是什么？为什么？
  A："object"——历史遗留 bug（早期实现用对象标志位表示 null）。

## 小结

- 一律 let/const；const 默认，需要可变再 let。
- 8 种类型：7 基本 + 1 引用；引用类型共享引用，const 只锁引用。
- 只用 ===；模板字符串代替 + 拼接。
- 作用域是词法的：内层看外层，外层看不见内层；let 修好了 for 循环。

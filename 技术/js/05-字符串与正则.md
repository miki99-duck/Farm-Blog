# 第5章 字符串与正则

> 一句话讲清：**字符串是前端处理最多的类型（接口返回、渲染、校验全在它），
> 正则负责"按模式找/换/验"——会写最常用的几个就够覆盖 90% 场景。**
> Java 对照：String 方法几乎同名（split/indexOf/replace）；正则语法基本相同
> （JS 用 /pattern/ 字面量而非字符串，细节略有差异）。

## 5.1 字符串高频方法速查

```js
const s = ' Hello, World! ';

// 去空格
s.trim();                   // "Hello, World!"（去除两端空白）

// 大小写
'abc'.toUpperCase();        // "ABC"
'ABC'.toLowerCase();        // "abc"

// 查找
s.indexOf('World');         // 7（找不到返回 -1）
s.includes('World');        // true（现代首选）
s.startsWith(' H');         // true
s.endsWith('! ');           // true

// 截取
s.slice(7, 12);             // "World"（slice 和 substring 都行，slice 更一致）
s.slice(-6);                // "orld! "（支持负索引，从后往前）

// 替换（注意：默认只替换第一个！）
'abc-abc'.replace('a', 'X');     // "Xbc-abc"
'abc-abc'.replaceAll('a', 'X');  // "Xbc-Xbc"（replaceAll 是现代的）

// 拆分 / 拼接
'a,b,c'.split(',');         // ["a","b","c"]
['a','b'].join('-');        // "a-b"

// 补齐（表格/编号常用）
'7'.padStart(3, '0');       // "007"
'7'.padEnd(3, '.');         // "7.."

// 重复与包含判断
'ab'.repeat(3);             // "ababab"
```

业务高频组合：设备编号格式化

```js
const code = 'CR007';
const padded = code.padStart(8, '0');   // "000CR007"——数据库排序友好
```

## 5.2 正则基础：字符、量词、位置（三块拼图）

```js
// 字面量写法：/模式/修饰符
// 字符类
/^[0-9]+$/.test('123');     // true（纯数字）
/^[a-zA-Z]+$/.test('abc');  // true（纯字母）
/\d{4}/.test('2026');       // \d = 数字，{4} = 恰好4个

// 量词
// * 0个或多个、+ 1个或多个、? 0或1个、{n,m} n到m个
/^\d+$/.test('42');          // true
/^1[3-9]\d{9}$/.test('13812345678');  // true（手机号常用）

// 位置锚点
// ^ 开头、$ 结尾、\b 单词边界
/^http/.test('https://x');   // true

// 修饰符
// g 全局匹配、i 忽略大小写、m 多行（^$ 作用于每行）
'Hello hello'.match(/hello/gi);   // ["Hello","hello"]
```

三个高频业务正则（背下来直接用，RuoYi 表单校验里都有）：

```js
// 身份证 18 位（简版校验）
/^\d{17}[\dXx]$/.test('410101199001011234');   // true

// 邮箱（常用简版）
const emailRe = /^[\w.-]+@[\w-]+(\.[\w-]+)+$/;
emailRe.test('user@example.com');               // true

// 中文字符（昵称/名称校验）
/^[\u4e00-\u9fa5]{2,10}$/.test('张三');         // true
```

## 5.3 正则三操作：test / match / replace / exec

```js
// ① test：只要布尔（校验用）
/^\d+$/.test('123');           // true

// ② match：找内容（提取用）
'订单号:20260901, 设备:CR007'.match(/\d+/g);
// ["20260901","007"]（g 返回所有匹配的数组）

// ③ replace：替换（清洗/格式化用）
'138-1234-5678'.replace(/-/g, '');         // "13812345678"（去掉所有横线）

// ④ 捕获组：() 提取片段
const m = 'IP: 192.168.1.10'.match(/(\d+)\.(\d+)\.(\d+)\.(\d+)/);
// m[0]="192.168.1.10" m[1]="192" m[2]="168" m[3]="1" m[4]="10"

// 捕获组在 replace 里用 $1
'张三(男)'.replace(/\((.+)\)/, '【$1】');   // "张三【男】"
```

面试手写高频：手机号脱敏

```js
function maskPhone(phone) {
  return String(phone).replace(/^(\d{3})\d{4}(\d{4})$/, '$1****$2');
}
maskPhone('13812345678');   // "138****5678"

// 名字脱敏：张**（保留首字）
function maskName(name) {
  return name.replace(/^(\S).*$/, '$1**');
}
maskName('张三丰');   // "张**"
```

## 5.4 正则的坑（面试爱问的"玄学"）

| 坑 | 现象 | 原因/解法 |
|----|------|----------|
| test/g 结果忽 true 忽 false | 同一条正则多次 test | g 模式 lastIndex 会移动；校验用去掉 g |
| 元字符没转义 | 匹配 . 或 ( 失败 | 用 \\. \\( 转义 |
| 贪婪匹配 | 找太长了 | 加 ? 变懒惰：`<.+?>` 最小匹配 |
| 中文按字符算 | length 数不准 | 用 [...str].length 或 Array.from 处理码点 |
| 正则写复杂 | 没人看得懂 | 拆分子正则 + 注释（正则/x 模式） |
| 回溯爆炸 | 长输入卡死 | 避免嵌套量词如 (a+)+ —— 生产用简单模式 |

```js
// 贪婪 vs 懒惰示例
const html = '<b>加粗</b><i>斜体</i>';
html.match(/<.+>/);      // ["<b>加粗</b><i>斜体</i>"]（贪婪：吞到最后一个 >）
html.match(/<.+?>/);     // ["<b>"]（懒惰：最短匹配）
```

## 5.5 正则以外的解析工具（能不用正则就别用）

```js
// URL 解析：用 URL 对象而不是正则
const u = new URL('https://example.com/api/devices?page=2&size=10');
u.pathname;        // "/api/devices"
u.searchParams.get('page');   // "2" —— 参数解析一行搞定

// 时间日期：Date 对象 + 格式化库（dayjs）而不是手写正则
const d = new Date();
d.getFullYear(); d.getMonth() + 1; d.getDate();

// 数字格式化：toLocaleString / 国际化 API
(1234567.8).toLocaleString('zh-CN');   // "1,234,567.8"
```

原则：**优先用语言/库提供的解析能力，正则留给"模式校验与复杂提取"。**

## 5.6 字符串与类型转换（小坑合集）

```js
// 数字 → 字符串
String(42);      // "42"
(42).toString(); // "42"
'' + 42;         // "42"（隐式，不推荐）

// 字符串 → 数字
Number('42');        // 42
+'42';               // 42（一元 +，不推荐写）
parseInt('42px', 10); // 42（带单位场景才用；第二个参数 10 必须写）

// 布尔 → 字符串
String(true);    // "true"

// JSON 互转（接口数据进出的核心）
JSON.stringify({ a: 1 });   // '{"a":1}'
JSON.parse('{"a":1}');      // {a:1}
```

## 5.7 面试自测

- Q：字符串方法中 replace 和 replaceAll 区别？
  A：replace 默认替换第一处；replaceAll 全部（或 replace 配合 /g 正则）。
- Q：常见手写正则？★
  A：手机号 /^1[3-9]\d{9}$/、邮箱、身份证、纯数字。
- Q：贪婪和懒惰匹配？
  A：默认贪婪（尽量长），加 ? 变懒惰（尽量短）。
- Q：test 为什么有时忽 true 忽 false？
  A：g 模式下 lastIndex 移动；校验场景去掉 g。

## 小结

- 字符串方法表记住 slice/includes/replaceAll/padStart 就够日常用。
- 正则三件：字符类（\d）、量词（+ * ? {n,m}）、锚点（^ $）；test 校验、match 提取、replace 替换。
- 脱敏/校验类手写题是面试高频，背模板。
- 能用 URL/Date 等解析就别上正则。

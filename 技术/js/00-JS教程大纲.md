## 三、贯穿全书的思维主线（5 句）

1. **JS 是"动态类型 + 单线程 + 事件驱动"的语言**——和 Java 最大的三个差异，处处围绕它。
2. **值是类型的主角，变量只是"标签"**：基本类型传值，引用类型传引用。
3. **this 谁调用指向谁**：箭头函数没有自己的 this。
4. **任何耗时操作都进"事件循环"**：先同步后异步，Promise 和 setTimeout 有固定排队顺序。
5. **函数是一等公民**：能当参数、能当返回值——闭包和高阶函数全靠它。

## 四、Java 对照表（学习最快通道）

| 概念 | Java | JavaScript |
|------|------|-----------|
| 变量声明 | int x = 1 | let x = 1（let/const） |
| 类型 | 编译期强类型 | 运行期动态类型（typeof） |
| 函数 | 方法（属于类） | 一等公民，独立存在 |
| 类 | class + 接口 | class（本质还是函数）+ 无接口 |
| 并发 | 多线程 | 单线程 + 事件循环 + 微任务 |
| 集合 | List/Map | 数组是主角 + Map/Set |
| 异常 | try-catch | try-catch（异常不检查） |
| 模块 | Maven 依赖 + import | npm 包 + import/export |

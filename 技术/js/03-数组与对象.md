# 第3章 数组与对象（业务逻辑到处都是它）

> 一句话讲清：**JS 里数组是主力集合（Java 的 List/Stream 二合一），
> 对象是字典/POJO 二合一；map/filter/reduce 三兄弟解决 80% 的数据处理。**
> Java 对照：数组方法 ≈ Stream API（filter/map/collect）；
> 对象 ≈ HashMap + POJO（访问属性像 map.get）。

## 3.1 数组的基本操作（增删改查）

```js
// 创建
const empty = [];
const nums = [1, 2, 3];
const mixed = [1, 'a', { on: true }];   // 数组可以混装类型（不推荐）

// 增删（注意位置）
nums.push(4);        // 尾部加 → [1,2,3,4]
nums.pop();          // 尾部删 → [1,2,3]
nums.unshift(0);     // 头部加 → [0,1,2,3]
nums.shift();        // 头部删 → [1,2,3]

// 查
nums.length;         // 3
nums.indexOf(2);     // 1（找到下标）
nums.includes(3);    // true

// 合并/切片
const a = [1, 2], b = [3, 4];
[...a, ...b];        // [1,2,3,4]（展开合并，现代写法）
a.concat(b);         // 老写法
a.slice(1);          // [2]（截取，不改原数组）
```

## 3.2 三兄弟：map / filter / reduce（比 Stream 更简洁）

```js
// map：一对一转换（Java Stream.map）
const devices = [
  { id: 1, name: '调压器A', online: true },
  { id: 2, name: '阀门B',   online: false },
];
const names = devices.map(d => d.name);
// ["调压器A", "阀门B"]

// filter：筛选（Java Stream.filter）
const online = devices.filter(d => d.online);
// [{id:1, name:'调压器A', online:true}]

// reduce：归约（Java Stream.reduce）—— 最万能也最烧脑
const total = nums.reduce((acc, cur) => acc + cur, 0);
// 1+2+3 = 6（acc 是累计值，0 是初始值）

// 组合链式：筛选在线设备 → 取名字 → 拼字符串（前后端都这风格）
const summary = devices
  .filter(d => d.online)
  .map(d => d.name)
  .join('、');
// "调压器A"
```

三个记忆锚点：**map 变换、filter 筛选、reduce 汇总**；输入数组、输出新数组（不修改原数组，纯函数风格）。

面试手写：把数组里每个数字翻倍并挑出偶数：

```js
const evenDoubled = [1, 2, 3, 4, 5, 6]
  .map(n => n * 2)          // [2,4,6,8,10,12]
  .filter(n => n % 2 === 0); // [2,4,6,8,10,12]（全偶数）
```

## 3.3 其他高频数组方法

```js
// find：找第一个满足的（返回元素，不是数组）
const dev = devices.find(d => d.id === 2);   // {id:2,...}

// some / every：判断"有至少一个/全部"
devices.some(d => d.online);     // true
devices.every(d => d.online);    // false

// sort：排序（注意：默认按字符串排！必须传比较函数）
[10, 9, 100].sort();              // [10, 100, 9] ❌ 字符串排序的坑
[10, 9, 100].sort((a, b) => a - b);  // [9, 10, 100] ✅ 升序
devices.sort((x, y) => x.id - y.id); // 按对象字段排序

// forEach：遍历副作用（没有返回值；能 map 就别用）
devices.forEach(d => console.log(d.name));

// 分组（现代 Object.groupBy，2024 后可用；老项目手写 reduce）
const byOnline = Object.groupBy(devices, d => d.online ? 'on' : 'off');
```

## 3.4 解构与展开（现代写法的第一生产力）

```js
// 数组解构：按位置取（常用于 promise.all 结果、交换变量）
const [first, second] = [10, 20, 30];
// first=10 second=20
let x = 1, y = 2;
[x, y] = [y, x];    // 一行交换（不需要第三个变量）

// 对象解构：按名取 + 重命名 + 默认值
const user = { name: '张三', age: 30, city: '郑州' };
const { name, age: userAge, city = '未知' } = user;
// name="张三" userAge=30（重命名） city="郑州"

// 函数参数解构：接收对象参数（第2章 queryDevices 已见）

// 展开运算符：复制/合并（浅拷贝）
const copy = { ...user };            // 新对象，字段同 user
const merged = { ...user, role: 'admin' };   // 追加字段
const arrCopy = [...devices];        // 数组浅拷贝
```

**对象合并/更新是一等常用**：Vue/RuoYi 里"更新某个字段"标准写法：

```js
// 不可变更新：不直接改原对象，返回新对象（配合 useState/redux 思想）
let state = { count: 1, list: [] };
state = { ...state, count: state.count + 1 };
// 再深一层：更新对象数组里的某一项
state = {
  ...state,
  list: state.list.map(item =>
    item.id === targetId ? { ...item, online: true } : item
  ),
};
```

## 3.5 对象：Map / Set 与普通对象的取舍

```js
// 普通对象当字典用：key 只能是字符串/Symbol
const dict = { '0101': '温度', '0102': '压力' };
dict['0103'] = '流量';          // 增
delete dict['0101'];            // 删
Object.keys(dict);              // ["0102","0103"]

// Map：key 可以是任意类型，有大小/遍历 API —— 真正的字典
const m = new Map();
m.set('a', 1);
m.set(42, 'number key');        // key 可以是数字
m.get('a');                     // 1
m.has('a');                     // true
m.size;                         // 2
m.delete('a');

// Set：去重神器
const ids = [1, 2, 2, 3, 3, 3];
const unique = [...new Set(ids)];   // [1, 2, 3] —— 一行去重
```

选择建议：**需要"键值对且键是动态的"用 Map；固定字段的数据结构用普通对象；
去重用 Set；不要用普通对象当高频读写的字典（原型链污染、没有 size）。**

## 3.6 深拷贝 vs 浅拷贝（高频面试）

```js
// 浅拷贝：只复制第一层，内部对象仍是引用共享
const original = { a: 1, inner: { b: 2 } };
const shallow = { ...original };
shallow.inner.b = 99;
console.log(original.inner.b);   // 99 —— 内部还是同一个！

// 深拷贝（现代）：structuredClone 是正规军（2022 后浏览器支持）
const deep = structuredClone(original);
deep.inner.b = 7;
console.log(original.inner.b);   // 2 ✅ 完全独立

// 旧写法：JSON 序列化（注意：丢失 undefined/函数/Date 类型）
const jsonDeep = JSON.parse(JSON.stringify(original));
```

面试讲法："展开/解构都是浅拷贝；内部对象共享；要完全独立用 structuredClone，
JSON 方案会丢 undefined/函数/特殊类型。"

## 3.7 常见坑快查

| 坑 | 现象 | 解法 |
|----|------|------|
| sort 结果怪 | 默认字符串排序 | 传比较函数 (a,b)=>a-b |
| map 里改了原对象 | 意外副作用 | 拷贝后修改 {...item, ...} |
| 深改没生效 | 浅拷贝 | structuredClone / 逐层展开 |
| 数组清空写法 | 重新赋值丢引用 | arr.length = 0 或 arr.splice(0) |
| 判空数组 | !arr 一直是 false | arr.length === 0 |
| forEach 想中断 | return 不生效 | 用 for...of + break，或 some 返回 true 短路 |

## 3.8 面试自测

- Q：map、filter、reduce 分别干什么？★
  A：变换/筛选/归约；不会改原数组，返回新值。
- Q：sort 为什么结果不对？
  A：默认按字符串比较；传比较函数。
- Q：展开运算符是深拷贝吗？
  A：不是，浅拷贝；深拷贝 structuredClone。
- Q：Map 和普通对象区别？
  A：key 类型（任意 vs 字符串）、size、遍历 API、原型链。
- Q：怎么一行去重？
  A：[...new Set(arr)]。

## 小结

- 数组三兄弟 map/filter/reduce + find/some/every 覆盖 90% 业务处理。
- 解构 + 展开 = 现代 JS 的"复制/合并/取值"主力，注意浅拷贝边界。
- Map/Set 该用就用，普通对象别当字典高频写。
- 面试手写题库核心就在这章：翻倍筛选、去重、按字段更新数组。

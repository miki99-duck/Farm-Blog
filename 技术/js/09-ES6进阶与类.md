# 第9章 ES6+ 进阶与类（class / 新语法速览）

> 一句话讲清：**class 是"语法糖"（内部还是函数+原型），新语法（可选链、空值合并、
> 展开、解构）是为了"写更少、错更少"。JS 的类模型和 Java 有本质区别——原型链。**
> Java 对照：class 语法很熟；但记住 JS 没有"类在编译期定死"，class 本质是函数，
> 继承是"原型链"而不是虚拟机级继承。

## 9.1 class：熟悉的语法，不同的本质

```js
class Device {
  // 构造器（Java 构造方法）
  constructor(id, name) {
    this.id = id;
    this.name = name;
    this.online = false;
  }

  // 实例方法（挂到原型上）
  start() {
    this.online = true;
    console.log(`${this.name} 启动`);
  }

  // 静态方法（Java static）
  static fromRow(row) {
    return new Device(row.id, row.name);
  }

  // 字段声明（现代：直接在类体里）
  // status = 'normal';   // 实例字段默认值
}

const d = Device.fromRow({ id: 1, name: 'CR007' });
d.start();                 // "CR007 启动"

// 继承（extends）
class GasDevice extends Device {
  constructor(id, name, pressure) {
    super(id, name);           // 必须先 super（Java 同规则）
    this.pressure = pressure;
  }
  // 重写
  start() {
    super.start();             // 调用父类方法
    console.log('燃气设备特例处理');
  }
}
```

核心认知（面试会挖）：**class 只是语法糖**，下面两行基本等价：

```js
class A { hello() { return 'hi'; } }
// 等价于（本质）：
function A() {}
A.prototype.hello = function () { return 'hi'; };
```

面试金句："JS 的 class 是构造函数的语法糖，实例方法在 prototype 上；
继承通过原型链实现——这跟 Java 的类继承模型完全不同，只是长得像。"

## 9.2 可选链 ?. 与空值合并 ??（写 Vue 模板/接口数据时的高频救命符）

```js
// 老的防御写法（又长又丑）
const name = user && user.info && user.info.name;

// 可选链：一路安全访问，断了返回 undefined
const name = user?.info?.name;      // 任何一环为 null/undefined 就返回 undefined

// 典型场景：接口返回的数据结构可能缺层
const city = resp?.data?.user?.address?.city ?? '未知';
```

```js
// ?? 空值合并：只在 null/undefined 时兜底
const a = 0 ?? '兜底';       // 0（0 不是空值！）
const b = null ?? '兜底';    // '兜底'

// 对比 || ：0/''/false 都会被当成假值兜底——这是历史坑
const c = 0 || '兜底';       // '兜底' ❌ 0 是合法值却被替换

// 规则：判空用 ??，逻辑或关系才用 ||
```

面试题：`undefined ?? 'a'` = 'a'；`null ?? 'a'` = 'a'；
`0 ?? 'a'` = 0；`'' ?? 'a'` = ''。✅

## 9.3 结构语法全家桶速览（第3章见过，这里归拢）

```js
// 数组解构 + 剩余
const [head, ...rest] = [1, 2, 3, 4];   // head=1 rest=[2,3,4]
const [a, , c] = [1, 2, 3];             // 跳位：a=1 c=3

// 对象解构 + 剩余
const { x, ...others } = { x: 1, y: 2, z: 3 };
// x=1 others={y:2,z:3}（剔除某些字段的"白名单化"）

// 函数参数默认 + 解构（第2章已见）
function f({ a = 1, b } = {}) {}

// 展开复制/合并（第3章已大量使用）
const merged = { ...base, ...patch };   // 后覆盖前
```

## 9.4 生成器与迭代器（了解即可，面试偶尔问）

```js
// 生成器：* 函数 + yield 暂停
function* idGenerator() {
  let id = 1;
  while (true) yield id++;
}
const gen = idGenerator();
gen.next().value;   // 1
gen.next().value;   // 2
```

用途：惰性大序列（分页枚举）、配合 Symbol.iterator 让对象可遍历。
面试提到即可："生成器是惰性迭代，next() 才往下走；async/await 内部也复用了类似机制。"

## 9.5 Proxy 与 Reflect（Vue3 响应式的底层）

```js
// 拦截对象访问：读/写/删都能加钩子
const target = { count: 1 };
const proxy = new Proxy(target, {
  get(obj, key) {
    console.log('读', key);
    return obj[key];
  },
  set(obj, key, value) {
    console.log('写', key, value);
    obj[key] = value;
    return true;
  }
});
proxy.count;        // 读 count
proxy.count = 2;    // 写 count 2
```

概念认知：Vue2 用 Object.defineProperty 做响应式（有数组/新增属性限制），
Vue3 用 Proxy 全面代理。面试讲这个 = "我理解框架底层在做什么"。

## 9.6 其他高频新语法（背结论即可）

```js
// 数字分隔符：可读性
const price = 1_000_000;         // = 1000000

// 幂运算
2 ** 10;                         // 1024（Math.pow 替代）

// includes 数组版
[1, 2, 3].includes(2);           // true

// Object 快捷
Object.keys(obj); Object.values(obj); Object.entries(obj);
Object.fromEntries([['a', 1]]);  // {a:1}

// Array 便捷初始化
Array.from({ length: 5 }, (_, i) => i);   // [0,1,2,3,4]
Array(3).fill(0);                        // [0,0,0]
```

## 9.7 Symbol：唯一标识

```js
// 每次创建唯一，常用于对象私有键/常量
const RED = Symbol('red');
const RED2 = Symbol('red');
RED === RED2;            // false（内容一样也两个不同！）

// 对象的"隐藏"键
const obj = { [Symbol('h')]: 1 };   // Symbol 键不会被 Object.keys 遍历到
```

面试一题：Symbol 有什么用？——"生成唯一值，避免命名冲突、做对象非枚举键。"

## 9.8 常见坑快查

| 坑 | 现象 | 解法 |
|----|------|------|
| class 方法里 this 丢 | 回调里调用方法 | 箭头函数方法/绑定（第2章） |
| 忘记 super | 报错 | 子类构造器必须 super 先行 |
| || 兜底吞掉 0 | 合法 0 被替换 | 用 ?? |
| 可选链只管 null/undefined | 0/'' 不短路 | 符合预期；误用 ?. 判断需要明确条件 |
| Object.keys 顺序 | 数字键先排 | 需要顺序用数组/Map |
| 解构 undefined 报错 | 解构一个不存在对象 | 默认值或先 ?. ：const {a} = obj ?? {} |

## 9.9 面试自测

- Q：class 的本质？★
  A：构造函数的语法糖；实例方法在 prototype；继承是原型链。
- Q：?. 和 ?? 什么区别？
  A：?. 安全访问属性；?? 只在 null/undefined 时兜底（不吞 0/''）。
- Q：Vue2 和 Vue3 响应式底层？
  A：Vue2 defineProperty 逐属性（数组/新增属性受限）；Vue3 Proxy 全对象代理。
- Q：Symbol 干什么用？
  A：唯一值；防冲突、非枚举对象键。

## 小结

- class 语法糖 + 原型链本质；继承先 super。
- 可选链 ?. 和空值合并 ?? 是现代判空标配（别用 || 兜底 0）。
- Proxy 是响应式底层（Vue3），生成器是惰性迭代。
- 新语法都是"更少代码、更少错"，日常写码大量用。

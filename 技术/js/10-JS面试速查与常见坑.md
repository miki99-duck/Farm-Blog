# 第10章 JS 面试速查与常见坑（考前 30 分钟）

> 使用方式：先自己答，再对答案；★ 是最高频。答不上来回对应章节。
> 这一章同时是"写代码遇到诡异行为"时的排查字典——90% 的"玄学"都在这 15 个坑里。

## A. 知识点速查（40 问版）

### 变量与类型（8）

1. var / let / const 区别？★★
   答：var 函数作用域+可重复声明+提升；let/const 块级+不可重复+暂时性死区；
   const 防重新赋值（对象内容可变）。
2. 基本类型 vs 引用类型？★
   答：值 vs 引用；赋值/传参的拷贝语义不同；const 锁引用不锁内容。
3. 基本类型有哪些？typeof null 是什么？
   答：number/string/boolean/undefined/symbol/bigint/null；typeof null === "object"（历史遗留）。
4. == 和 ===？★
   答：=== 类型+值严格相等；== 隐式转换（禁止用）；判空用 x == null 例外。
5. 假值有哪些？
   答：false、0、''、null、undefined、NaN；其余全真（'0' 是真值）。
6. 隐式转换注意什么？
   答：'5'+3="53"（拼接）；'5'-3=2；规范：拼接用模板字符串、转换用 Number()。
7. NaN 有什么特殊？
   答：NaN !== NaN；判断用 Number.isNaN()。
8. 深拷贝怎么做？★
   答：structuredClone()；JSON 方式丢失 undefined/函数/Date；展开是浅拷贝。

### 函数与作用域（7）

9. this 指向规则？★★
   答：谁调用指向谁；方法调用=对象；直接调用=undefined/全局；call/apply/bind 显式；箭头词法绑定。
10. 箭头函数 vs 普通函数？★
    答：无自己的 this（继承外层）、不能 new、无 arguments、无 prototype、写法短。
11. 闭包是什么？★
    答：函数+被私有化的外层环境；外层变量不回收--用于私有变量/防抖节流/柯里化。
12. var 循环坑怎么修？
    答：let 声明循环变量（每次迭代独立绑定）。
13. call / apply / bind 区别？★
    答：call 逐个参、apply 数组参（都立即执行）、bind 返回新函数（不立即执行）。
14. 函数声明和表达式区别？
    答：声明有提升可先调用；表达式无提升（变量未初始化报错）。
15. 高阶函数是什么？
    答：接收/返回函数的函数——map/filter/reduce、withLog、柯里化。

### 数组与对象（8）

16. map / filter / reduce？★★
    答：变换/筛选/归约；不修改原数组。reduce(acc, cur) 带初始值。
17. sort 的坑？
    答：默认按字符串排；必须传比较函数 (a,b)=>a-b。
18. 数组去重？
    答：[...new Set(arr)]。
19. 深/浅拷贝区别？
    答：浅只复制一层共享内部引用；深完全独立。structuredClone。
20. Map vs 普通对象？★
    答：key 任意类型 vs 字符串；有 size/遍历 API；对象有原型链。
21. 解构和展开？
    答：解构按位置/按名取值；展开 ...复制/合并/传参（浅拷贝）。
22. 不可变更新数组项怎么写？
    答：map + {...item, ...patch}。
23. find vs filter？
    答：find 返回第一个匹配元素（或 undefined）；filter 返回数组。

### 异步与事件循环（6）

24. Promise 三状态？★
    答：pending/fulfilled/rejected；一旦改变不可逆。
25. Promise.all 与 allSettled？★
    答：all 全成功才走、一个失败全失败；allSettled 等全部结果不管成败。
26. async/await 原理？
    答：async 函数返回 Promise；await 挂起当前函数等待结果；本质还是 then 回调。
27. 事件循环顺序？★★
    答：同步栈 → 微任务清空 → 宏任务；微任务优先。
28. 微任务有哪些？宏任务有哪些？
    答：微：Promise.then/queueMicrotask；宏：setTimeout/setInterval/I/O。
29. Promise 构造器为什么先执行？
    答：new Promise 里的代码是同步的；.then 才进微任务队列。

### DOM/网络/其他（7）

30. 事件传播三阶段？★
    答：捕获→目标→冒泡；监听默认冒泡阶段触发。
31. 事件委托？
    答：监听挂父级利用冒泡统一处理（e.target.closest）；省监听器、动态元素免重绑。
32. stopPropagation vs preventDefault？★
    答：前者停冒泡；后者阻止默认行为（跳转/提交）。
33. 同源策略？跨域方案？★★
    答：协议+域名+端口相同；CORS/代理/JSONP。
34. localStorage/sessionStorage/cookie？★
    答：永久/关页清/可过期且自动携带；安全：HttpOnly 防 XSS。
35. fetch 与 axios？★
    答：axios 有拦截器/自动 JSON/超时；fetch 底层（404 不 reject 要手动判断 res.ok）。
36. XSS 怎么防？
    答：用户输入只进 textContent；富文本白名单（DOMPurify）；token 配 HttpOnly。

### 进阶（4）

37. class 的本质？★
    答：构造函数语法糖；方法在 prototype；继承是原型链。
38. 可选链 ?. 和 空值合并 ?? ？
    答：?. 安全访问；?? 只在 null/undefined 兜底（不吞 0/''）。
39. Vue2/Vue3 响应式区别？
    答：defineProperty 逐属性 vs Proxy 全对象。
40. export default 和 export 区别？
    答：default 每文件一个、导入随便命名；命名导出按名导入。

## B. 高频手写题（现场写，每题 <2 分钟）

```js
// 1. 深拷贝一个对象（简洁版）
const deepClone = (o) =>
  o && typeof o === 'object' ? structuredClone(o) : o;

// 2. 数组去重
const unique = [...new Set([1, 2, 2, 3])];   // [1,2,3]

// 3. 数组按某字段排序（升序）
arr.sort((a, b) => a.score - b.score);

// 4. 手机号脱敏
const mask = ph => String(ph).replace(/^(\d{3})\d{4}(\d{4})$/, '$1****$2');

// 5. 防抖（背模板）
function debounce(fn, delay = 300) {
  let t;
  return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), delay); };
}

// 6. 节流（背模板）
function throttle(fn, interval = 300) {
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last >= interval) { last = now; fn(...args); }
  };
}

// 7. 事件委托：点击 li 打印内容
list.addEventListener('click', e => {
  const li = e.target.closest('li');
  if (li) console.log(li.textContent);
});

// 8. 手写 Promise.all（概念版）
function promiseAll(promises) {
  return new Promise((resolve, reject) => {
    const results = [];
    let done = 0;
    promises.forEach((p, i) =>
      Promise.resolve(p).then(v => {
        results[i] = v;
        if (++done === promises.length) resolve(results);
      }).catch(reject)
    );
  });
}
```

## D. 面试问答套路（一页版）

1. "为什么 JS 是单线程的？"
   答：因为要操作 DOM；多线程同时改 DOM 会乱。靠事件循环 + 异步实现"不卡"。
2. "Promise 和 async/await 你更常用哪个？"
   答：声明 async/await 写得更像同步、try-catch 接错；并发聚合时用 Promise.all；
   细节控制（race/超时）用 Promise API。
3. "手写过什么组件/工具？"（准备好例子）
   答：防抖节流工具、request 封装（拦截器）、深拷贝、日期格式化
   ——挑 2 个讲思路（输入输出 + 边界）。
4. "为什么说 Rust/TS 会补 JS 的坑？"
   答：TS 静态类型在编译期拦类型错误——类比说"等于给动态语言加 Maven 的编译检查"。
5. "最近在学什么前端技术？"
   答：Vue3 组合式 + Vite、ES2024 新特性；贴项目：RuoYi 是 Vue2，我在迁移到
   Vue3/组合式时对比理解响应式原理（Proxy vs defineProperty）。

## 小结

- 最高频五块：this、闭包、事件循环、Promise、==辨别——占面试 60%。
- 手写题都是"短小工具"：深拷贝、防抖、去重、脱敏、事件委托。
- 面试案例准备一个真实踩坑（如 401 循环、CORS、var 循环坑）。
- 动态类型是把双刃剑：自由但容易"静默错"，多用 ===、??、?.、严格模式。

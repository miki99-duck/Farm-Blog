## 三、贯穿全书的思维主线（先记住这 5 句）

1. **CSS 是"描述"，不是"编程"**：你是在描述元素最终长什么样，浏览器负责计算。
2. **一切争议都能用"层叠"解释**：特定度 + 来源 + 顺序，三权分立。
3. **布局先想 flex/grid，float 只在文字环绕时用**（老教程已经过时）。
4. **长宽高用 rem，1px 用 px，适配屏幕用 vw/%**。
5. **遇到样式不生效，逆推：选择器命中了吗？特定度够吗？被谁覆盖了？**（85% 的问题是这三步）

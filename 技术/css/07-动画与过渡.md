# 第7章 动画与过渡

> 一句话讲清：**transition 是"状态变化的平滑过程"（A→B），animation 是"独立剧本"
> （预定义的多阶段表演）；transform 是它们的"位移/变形引擎"。**
> 后端类比：transition 约等于"平滑状态机的状态迁移"，animation 约等于"定时任务调度脚本"，
> transform 约等于"对渲染层的仿射变换"。
> 面试重点：问 animation 原理/性能时，能答出"GPU 合成层"就是高级答案。

## 7.1 transition：让变化"丝滑"而不是"跳变"

```css
.btn {
  background: #409eff;
  transition: background 0.3s ease;   /* 属性 时长 缓动函数 */
}
.btn:hover { background: #337ecc; }   /* 0.3 秒平滑过渡，而不是瞬间变色 */
```

四要素拆解：

```
transition: property duration timing-function delay
           背景色     0.3s      ease          0s
```

- property：哪个属性变化要过渡（all = 全部，性能稍差；指定属性更清晰）
- duration：时长；delay：延迟开始
- timing-function 常用值：ease（默认，先快后慢）、linear（匀速）、
  ease-in（渐入）、ease-out（渐出）、cubic-bezier()（自定义曲线）

```css
.box {
  transition:
    transform 0.2s ease,
    box-shadow 0.3s ease 0.1s;   /* 多个属性可逗号并列，各自时长/延迟 */
}
```

四字口诀：**"不写 transition 就不存在动画，只有瞬间切换。"**

## 7.2 transform：位移/缩放/旋转/倾斜

transform 不改变布局（不触发重排！），只对元素做视觉变换——这也让它成为性能王者。

```css
/* 位移 */
transform: translateX(20px);        /* 右移 20px */
transform: translate(-50%, -50%);   /* 居中经典款（配合 absolute） */

/* 缩放 */
transform: scale(1.1);              /* 放大 1.1 倍（hover 卡片常见） */

/* 旋转 */
transform: rotate(45deg);           /* 顺时针 45°（loading 图标常见） */

/* 倾斜 */
transform: skewX(-10deg);           /* X 轴斜切，标签效果 */

/* 组合：空格分隔 */
transform: translateY(4px) scale(1.05);
```

经典组合：悬浮卡片"上浮 + 阴影加深"

```css
.card {
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}
.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 24px rgba(0,0,0,.12);
}
```

## 7.3 animation：直接演剧本

```css
@keyframes 名称 {
  from { ... }  /* 或 0% */
  to   { ... }  /* 或 100% */
}

.spinner {
  animation: spin 1s linear infinite;   /* 名称 时长 缓动 次数 */
}
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}
```

多阶段关键帧：

```css
@keyframes pulse {
  0%   { transform: scale(1); opacity: 1; }
  50%  { transform: scale(1.08); opacity: .8; }
  100% { transform: scale(1); opacity: 1; }
}
.dot { animation: pulse 1.5s ease-in-out infinite; }   /* 呼吸灯/提示点 */
```

animation 常用子属性（面试能说出 5 个即可）：

| 子属性 | 含义 | 例 |
|--------|------|-----|
| animation-name | 剧本名 | pulse |
| animation-duration | 时长 | 1.5s |
| animation-timing-function | 缓动 | ease-in-out |
| animation-delay | 延迟 | 0.5s |
| animation-iteration-count | 次数 | infinite |
| animation-direction | 方向 | alternate（正反往返） |
| animation-fill-mode | 结束后状态 | forwards（停在最后一帧） |

## 7.4 实战：骨架屏（IoT 列表页必备 loading 效果）

```css
.skeleton {
  background: #eee;
  border-radius: 4px;
  height: 16px;
  animation: shimmer 1.2s linear infinite;
}
@keyframes shimmer {
  0%   { opacity: 1; }
  50%  { opacity: .4; }
  100% { opacity: 1; }
}
/* 用法：<div class="skeleton" style="width:60%"></div> */
```

## 7.5 性能必答：为什么 transform/opacity 流畅

浏览器渲染一帧的管线：

```
JS/样式 → 布局(Layout) → 绘制(Paint) → 合成(Composite)
```

- 改 **width/height/left/top**：触发布局 → 绘制 → 合成，整条管线全跑，慢。
- 改 **color/background**：跳过布局，但触发绘制，中速。
- 改 **transform/opacity**：**只触发合成**，GPU 合成层直接动，最快。

```css
/* 推荐：用 transform 做位移动画，而不是 left/top */
.badge { transition: transform 0.2s; }
.badge:hover { transform: translateX(8px); }

/* ❌ 避免：left 动画（每次重排，掉帧元凶） */
.badge { transition: left 0.2s; }
.badge:hover { left: 8px; }
```

面试金句："动画优先使用 transform 和 opacity，它们只走合成线程（GPU），
不触发重排重绘；width/height/top/left 动画会触发 Layout，移动端很容易掉帧。"

## 7.6 动效设计建议（少即是多）

1. 时长 150~300ms 是"自然"手感；超过 500ms 显得拖沓。
2. 缓动别全用 ease：进入用 ease-out（刹车感），退出用 ease-in。
3. 尊重系统偏好：用户关闭动画时禁用动效（现代无障碍要求）：

```css
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
```

## 7.7 常见坑快查

| 坑 | 现象 | 解决 |
|----|------|------|
| transition 不生效 | 属性写错/初始状态没写 | transition 定义在"默认状态"，不是 hover 上 |
| 动画最后跳回原位 | 没写 fill-mode | animation-fill-mode: forwards |
| 位移动画卡顿 | 用 left/top 驱动 | 换 transform: translate |
| 多个动画打架 | transform 被互相覆盖 | 组合写在同一 transform 或分开元素 |
| transform 把 fixed 弄坏 | 祖先 transform 改变包含块 | 结构上让 fixed 元素不挂在 transform 祖先下 |

## 7.8 面试自测

- Q：transition 和 animation 区别？
  A：transition 需要触发（hover 等）+ 只有起点终点；animation 用 @keyframes
  预定义多阶段，可自动循环、可逆。
- Q：哪些属性动画性能好？
  A：transform/opacity 只走合成层不重排；布局类属性（width/left）会重排。
- Q：transform 为什么能居中？
  A：translate(-50%,-50%) 相对自身尺寸偏移，无需知道宽高。
- Q：怎么在用户关闭动效时禁用动画？
  A：@media (prefers-reduced-motion: reduce)。

## 小结

- transition = 状态平滑，animation = 预编排剧本，transform = 高性能变换引擎。
- 性能铁律：动 transform/opacity，别动 width/left。
- 动效三原则：短、缓、可关闭。

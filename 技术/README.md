- 2026-10-05：**底色从「高饱和棋盘绿」改为柔和版**（改前改后都用无头浏览器截图核对过）
  原来 body 是 `#5a9e3a` 铺满整屏 + 22px 棋盘格（`#5a9e3a`/`#4f8f31`）。实测三个问题：
  ① 占可视面积 **34.2%**（1280×860 视口的像素占比）；② 棋盘两色 ΔL=**5.4%**，整屏纹理在跟内容抢注意力；

  改法（D 方案柔和档）：饱和 **63%→38%**、纹理改成 **1.8% 透明度**（像素质感还在，但几乎看不见）、
  自上而下轻微加深做纵深（顶 L 0.198 → 底 0.133）。副作用是好的：纸面面板与底色的对比
  从 **2.71:1 提到 3.48:1（顶部）/ 4.74:1（底部）**，面板反而更清楚；木牌与田块本来就靠

## 二、贯穿全书的思维主线（5 句）

1. **线程安全的本质是"共享可变数据 + 多线程"**，只共享、不变，或不变、多线程，都不会有问题。
2. **三大问题：原子性、可见性、有序性**，是设计并发工具（volatile / synchronized / Lock）的出发点。
3. **锁是"用性能换正确性"**：用互斥保证一致性，代价是阻塞和上下文切换，能不加就不加。
4. **synchronized 是"语法糖"，ReentrantLock 是"功能机"**：前者简单可靠，后者可中断/可超时/可多条件。
5. **线程池是生产标配**，禁止 `new Thread()` 和 `Executors.xxx()` 裸用。
